Philosophy

The difference between a page that looks "made by AI" and one that feels genuinely designed is intentionality.

The frontend-design skill pushes AI agents beyond their comfort zone of generic Inter-on-white-with-purple-gradient defaults. It demands bold aesthetic direction, distinctive font pairing, and unexpected spatial choices — the things that make a design memorable.

This entire page is pure HTML + CSS + vanilla JS. No framework. No build step. Just well-crafted code following strong design principles.
